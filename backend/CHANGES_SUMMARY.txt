🔄 DATA FLOW
───────────────────────────────────────────────────────────────────────────────

  1. PAYOUT CREATION
     User → API → create_payout() → Anchor API → Database → Response
                                       ↓
                              Save: rate, fee, tx_id, status
  
  2. BACKGROUND POLLING (every 30s)
     Worker → Query active payouts → For each:
                                      └─ Query Anchor API
                                      └─ Update DB if status changed
                                      └─ Log transition
  
  3. PAYOUT QUERIES
     API → get_payout(id) → Database → Response
     API → list_payouts(addr) → Database → Response
     GET /api/anchor/payout-status → Database → JSON Response
